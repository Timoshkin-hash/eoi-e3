# Экономика информатизации — экзаменационная задача №3

Репозиторий содержит воспроизводимое решение задачи **«Выбор ценовой стратегии для AI-сервиса по созданию контента»** для проекта «AI-Копирайтер». Notebook сравнивает Freemium, подписку, динамическое и персонализированное ценообразование по ARPU, LTV, LTV/CAC, прогнозной прибыли, NPV, чувствительности и стратегическим рискам.

## Структура

| Путь | Назначение |
|---|---|
| `notebooks/task_03_ai_pricing.ipynb` | Основной Notebook с расчётами, таблицами, графиками и выводами. |
| `data/task_03_ai_pricing_config.json` | Источник исходных данных и параметров модели. |
| `utils/calculations.py` | Переиспользуемые функции расчётов. |

| `docs/glossary.md` | Глоссарий терминов. |

## Ключевой вывод

По относительному сравнению стратегий максимальный NPV показывает **«Подписка»**. При этом прозрачный пересчёт с учётом разработки, поддержания и выбранного CAC даёт отрицательный NPV для всех четырёх вариантов. Поэтому «Подписка» является лучшей альтернативой среди заданных, но при текущих входных данных проект не следует запускать без изменения экономики модели.


## Запуск

```bash
python -m venv .venv
# Git Bash: source .venv/Scripts/activate
# PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

Открыть `notebooks/task_03_ai_pricing.ipynb` и выполнить ячейки сверху вниз.

Для экспорта HTML после выполнения:

```bash
python -m jupyter nbconvert --to html --output-dir reports --output task_03_report notebooks/task_03_ai_pricing.ipynb
```

## Ограничения

Годовая модель роста является укрупнённой. Churn используется непосредственно в LTV, но не моделируется помесячным оттоком в денежном потоке. Не моделируются налоги, маржинальность генерации, токеновые расходы, сегментация пользователей и изменение CAC при масштабе. Для прогноза прибыли канал CAC задаётся параметром `base_profit_cac_channel` в JSON.

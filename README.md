# Экономика информатизации — экзаменационная задача №3

Репозиторий содержит воспроизводимое решение задачи **«Выбор ценовой стратегии для AI-сервиса по созданию контента»** для проекта «AI-Копирайтер». Notebook сравнивает Freemium, подписку, динамическое и персонализированное ценообразование по ARPU, LTV, LTV/CAC, прогнозной прибыли, NPV, чувствительности и стратегическим рискам.

## Структура

| Путь | Назначение |
|---|---|
| `notebooks/task_03_ai_pricing.ipynb` | Основной Notebook с расчётами, таблицами, графиками и выводами. |
| `data/task_03_ai_pricing_config.json` | Исходные данные задачи. |
| `utils/calculations.py` | Переиспользуемые функции расчётов. |
| `reports/figures/` | Графики после выполнения Notebook. |
| `docs/methodology.md` | Методология и допущения. |
| `docs/glossary.md` | Глоссарий терминов. |
| `requirements.txt` | Зависимости проекта. |

## Ключевой вывод

По решению преподавателя рекомендуется стратегия **«Подписка»**. Она даёт самый высокий ARPU — 300 руб. в месяц, LTV — 6 000 руб. и LTV/CAC 7,5x при контент-маркетинге. Виральный канал даёт ещё более высокое LTV/CAC, но требует отдельного плана роста.

Notebook дополнительно выполняет прозрачный пересчёт NPV с включением 15 млн руб. разработки, 2 млн руб. ежемесячного поддержания и CAC контент-маркетинга 800 руб. Это позволяет показать расхождение с укрупнёнными NPV учебного решения и объяснить его на защите.

## Запуск

```bash
python -m venv .venv
# Git Bash: source .venv/Scripts/activate
# PowerShell: .venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

Открыть `notebooks/task_03_ai_pricing.ipynb` и выполнить ячейки сверху вниз.

Для экспорта HTML после выполнения:

```bash
python -m jupyter nbconvert --to html --output-dir reports --output task_03_report notebooks/task_03_ai_pricing.ipynb
```

## Ограничения

Годовая модель роста является укрупнённой. Churn используется непосредственно в LTV, но не моделируется помесячным оттоком в денежном потоке. Не моделируются налоги, маржинальность генерации, токеновые расходы, сегментация пользователей и изменение CAC при масштабе.

# Проверка решения задачи №3

## Общий результат

Notebook выполняется из чистого ядра без ошибок. Расчёты ARPU, LTV, LTV/CAC, прибыли и NPV связаны с JSON-конфигурацией и пересчитываются при изменении входных данных.

При исходной конфигурации лучшей по рассчитанному NPV является стратегия «Подписка», но её прозрачный NPV отрицателен. Поэтому экономически корректная формулировка — не «проект одобряется», а «из четырёх вариантов выбирается наименее убыточная стратегия для дальнейшей доработки; запуск при текущих параметрах не рекомендуется».

## Проверенные формулы

```text
ARPU = price × conversion
LTV = ARPU / churn
LTV/CAC = LTV / CAC

Прибыль года = ARPU × база пользователей × 12
               − ежемесячное поддержание × 12
               − CAC × новые пользователи

NPV = Σ CFₜ / (1 + r)ᵗ
```

Затраты на разработку относятся к денежному потоку нулевого года. Денежные потоки за три прогнозных года дисконтируются по годовой ставке из JSON.

## Существенные допущения

1. В годовой модели доход рассчитывается по базе пользователей на конец года, то есть модель не использует среднюю базу в течение года. Это допущение скорее завышает выручку и должно быть явно оговорено на защите.
2. Churn влияет непосредственно на LTV. В денежном потоке основной сценарий не моделирует помесячный отток когорт, потому что в условии нет расписания удержания пользователей. В чувствительности используется отдельное годовое приближение через долю удержания.
3. Канал CAC для прогноза прибыли теперь задаётся параметром `base_profit_cac_channel`, а не зашит в коде Notebook. В исходной конфигурации выбран контент-маркетинг.
4. Значение `market_growth_annual` используется для отображения условия. Расчётная траектория использует отдельный массив `growth_rates`, поскольку условие задаёт рост по годам как 100%, 50% и 20%.

## Методический вывод

Математически Notebook решает поставленные вопросы последовательно. Однако при отрицательном NPV нельзя представлять выбранную стратегию как уже выгодную. Следует разделять:

- лучшую стратегию среди заданных вариантов;
- экономически приемлемый проект.

В текущем наборе данных «Подписка» — лучшая относительная альтернатива, но проект требует повышения ARPU, снижения CAC, уменьшения постоянных затрат или пересмотра траектории роста.

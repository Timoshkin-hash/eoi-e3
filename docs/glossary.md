# Глоссарий

| Термин | Определение |
|---|---|
| ARPU | Средний доход на одного пользователя в месяц. В задаче учитывает конверсию: цена умножается на долю платных пользователей. |
| CAC | Customer Acquisition Cost — стоимость привлечения одного пользователя. |
| Churn | Доля клиентов, прекращающих пользоваться сервисом за период. |
| LTV | Lifetime Value — пожизненная ценность клиента, рассчитанная как ARPU / Churn. |
| LTV/CAC | Отношение пожизненной ценности клиента к стоимости его привлечения. |
| NPV | Чистая приведённая стоимость проекта с учётом дисконтирования денежных потоков. |
| Freemium | Бесплатный базовый доступ с конверсией части пользователей в платную версию. |
| Подписка | Регулярная фиксированная ежемесячная плата за доступ к сервису. |
| Динамическое ценообразование | Изменение цены в заданном диапазоне в зависимости от сегмента, спроса или условий использования. |
| Персонализированное ценообразование | Индивидуальное назначение цены или тарифа для конкретного пользователя или сегмента. |
| MRR | Monthly Recurring Revenue — регулярная ежемесячная выручка. |
| NRR | Net Revenue Retention — удержание регулярной выручки с учётом расширения и сокращения клиентов. |
